HireHub - Job Portal

HireHub is a full-stack MERN Job Portal that connects candidates and recruiters through a modern recruitment platform.

Features

- Candidate & Recruiter Authentication
- Candidate & Recruiter Profiles
- Job Search & Filtering
- Create, Update & Delete Jobs
- Save & Apply for Jobs
- Resume & Profile Photo Upload
- Company Logo Upload
- Application Status Management
- Interview Scheduling
- Real-time Communication with Socket.IO

Tech Stack

Frontend: React.js, Vite, JavaScript, Axios
Backend: Node.js, Express.js, REST API, JWT
Real-time: Socket.IO
Database: MongoDB
Tools: Git, GitHub, Postman, VS Code

Installation:

git clone https://github.com/Devadhinesh/HireHub-job-portal.git
cd HireHub-job-portal

cd backend
npm install
npm start

cd frontend
npm install
npm run dev
